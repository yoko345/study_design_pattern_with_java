`git diff main...HEAD` と `git log main...HEAD --oneline` を確認したうえで、ステップ 1 を完了後、ステップ 2〜4 を**確認なし**で順番に実行してください。

## ステップ 1: ステージング
未コミットの変更があるかどうかを確認する。
変更がある場合は適切なコミットメッセージ（**簡潔な1行**）を伴ってコミットをするのかを聞く。


## ステップ 2: リモートへ push

リモートにpushされていないコミットがある場合のみpushを行う。

```
git push -q -u origin <現在のブランチ名>
```

## ステップ 3: PR を作成

PR タイトルと本文を組み立て、`gh pr create` で PR を作成する。

- 本文のセクション構成（見出し名は固定）:
  - `### 概要` — 何のための PR か、結果として何が変わるかを短く
  - `### 背景` — なぜ必要か
  - `### 変更内容` — 変更ファイルごとの具体的な説明
- 「動作確認」セクションは**絶対に追加しない**（テストコマンドのないJava学習記事用リポジトリのため）
- プレースホルダ・`<!-- -->` コメントは使わず、実内容を書く

```bash
gh pr create --title "<タイトル>" --body "$(cat <<'EOF'
### 概要
...

### 背景
...

### 変更内容
...
EOF
)"
```

## ステップ 4: 完了を報告

作成された PR の URL をユーザーに伝える。
