`git diff main...HEAD` と `git log main...HEAD --oneline` を確認したうえで、以下の 3 ステップを**確認なし**で順番に実行してください。

## ステップ 1: リモートへ push

```
git push -q -u origin <現在のブランチ名>
```

## ステップ 2: PR を作成

PR タイトルと本文を組み立て、`gh pr create` で PR を作成する。

- 本文のセクション構成（見出し名は固定）:
  - `### 概要` — 何のための PR か、結果として何が変わるかを短く
  - `### 背景` — なぜ必要か
  - `### 変更内容` — 変更ファイルごとの具体的な説明
- 「動作確認」セクションは**絶対に追加しない**
- プレースホルダ・`<!-- -->` コメントは使わず、実内容を書く

```bash
gh pr create --title "<タイトル>" --body "$(cat <<'EOF'
### 概要
...

### 背景
...

### 変更内容
...
EOF
)"
```

## ステップ 3: 完了を報告

作成された PR の URL をユーザーに伝える。
